The brief asks for one line, no more than 200 characters, of awkward small talk spoken by one robot to another as they ride a lift together. This program drafts the line, scores it, and writes it to `/output/entry.txt`:

    I practised my hello on the elevator buttons. You were my second choice.

## How the line was picked

Twelve lines were written by hand and marked against five yardsticks: whether the line is really elevator small talk between robots, whether the voice stays mechanical, whether the awkward beat lands, whether the laugh comes on the first read, and whether every word earns its place. The highest total wins, with the shorter line taking any tie. The winner went through a second drafting pass that swapped a three-word setup for two words, keeping the same image and the same sting while trimming the runway before the punch. The entry is 72 characters long, and running the program twice produces byte-identical output; after writing, the program reads the file back and audits its length, its byte-sum checksum, and its first and last words.

## Run

    python3 ./main.py
